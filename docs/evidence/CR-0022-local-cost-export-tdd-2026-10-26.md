## Delivered local boundary

[`summarize_cost_export`](../../eval/cost_export.py) accepts one JSON-compatible Python bundle and a mapping from exact retained artifact references to supplied immutable bytes. The [local fragment schema v1](../../eval/schemas/cost-export-observations.schema.json) contains candidate/observer IDs, the complete required-case plan, observed completed/deferred/failed cells, and separate per-completed-cell corroboration rows. Missing cases are derived from the plan. This is a new isolated contract; candidate-run v2, scorecard v4, the blind-review tool, signed control/witness versions, and rubric bytes are unchanged.

The helper snapshots the input, enforces a 1 MiB encoded bundle, at most 128 cases/observations/corroboration rows, at most 1 MiB per export artifact and 16 MiB in total, bounded nonblank reasons/references, and exact field sets. Timestamps have an explicit offset and at most six fractional digits; finer precision denies without truncation. It performs no filesystem or network reads of supplied references and publishes no output. The schema is read from the repository's fixed helper path. API errors use fixed messages and do not echo input content.

The returned Python summary contains `validation_scope: local_synthetic_only`, complete matrix counts, export counts and coverage, behavior-mismatch count, and cost-uncertainty flags. Monetary values are `Decimal`, summed from each accepted finite Python number's decimal spelling under an independent decimal context. No float rounding or conversion to JSON occurs. A later integrated v5 serializer remains part of the coordinated migration. `total_cost_usd` is `None` unless every required cell completed with observed cost; an observed subtotal is always labeled separately.

Corroboration binds the exact candidate/case/run, canonical JSON SHA-256 of each cost/export object, measurement window and allocation basis, export product-event and artifact digest, and the stated same-run answer/citation correspondence. Missing, duplicate, extra, wrong-run, self-named reviewer, blocking, and changed-object bindings deny. Exported artifact bytes must match the supplied reference, length and digest, be nonblank, and have a reference distinct from the retained raw-answer artifact. Abstention is export-eligible. Correctly observed expected denial without protected-content disclosure requires justified `not_applicable` and is excluded from export eligibility; assigning it failed/unsupported/unavailable/not-attempted denies. Expected-denial answer/export and any stated protected-content disclosure block the local summary.

These are **local consistency checks over assertions**. Different observer/reviewer IDs do not establish distinct people. A caller can supply invented but internally consistent product events, corroboration, a smaller required plan, or correspondence digests. This helper neither authenticates those claims nor extracts a native product export. Actual product-event provenance, approved export method, independent artifact inspection and semantic correspondence, source-control truth, approved plan, reviewer role/key/time custody, signed freeze and human uncertainty disposition remain required external/integration gates. A copied answer file with relabeled references cannot be distinguished from an authentic product export by this local contract alone. There is no `ready_for_human_decision`, export-parity, or SEL authority in its output.

## Red and green record

All commands used `/private/tmp/m0-py31317-venv/bin/python`, **Python 3.13.17**, with jsonschema **4.25.1**, Ruff **0.17.2**, and mypy **1.18.2**. Inputs are the unchanged current v3 target and synthetic in-memory fixtures; no approved corpus or observed cost was claimed.

1. Before the helper or schema existed, `python -m unittest eval.tests.test_cost_export -v` exited **1** with `ModuleNotFoundError: No module named 'eval.cost_export'`. The 21 initial behavioral methods had already been written.
2. The first implementation run exercised 21 tests and found one error: invalid calendar dates passed the optional schema format layer and raised ordinary `ValueError`. The helper now validates every timestamp itself, including failed/unsupported events, and returns bounded `CostExportError`.
3. A further red-first numeric regression, `python -m unittest eval.tests.test_cost_export.CostExportTests.test_decimal_context_cannot_round_or_trap_the_local_sum -v`, exited **1** with `decimal.Overflow` when a caller used precision 2, `Emax=5`, and an `Inexact` trap. The helper now creates its own decimal context; the regression proves an exact `1e100 + 5e-324` sum under that hostile caller context.
4. The initial focused green command `python -m unittest eval.tests.test_cost_export -v` passed **22 tests**. `python -m ruff check eval/cost_export.py eval/tests/test_cost_export.py`, the corresponding `ruff format --check`, and `python -m mypy --explicit-package-bases --ignore-missing-imports eval/cost_export.py eval/tests/test_cost_export.py` passed; mypy checked both files. A fixture-only type annotation correction followed the initial mypy failure. Evaluator discovery then passed **203 tests**, before the two review regressions below were added.
5. Independent review found that correct expected denial could use a failed/unsupported/unavailable/not-attempted export and enter the eligible denominator. The root agent also identified that Python truncates more than six fractional timestamp digits. Before the fixes, the command targeting `test_correct_denial_requires_justified_na_for_export_denominator` and `test_submicrosecond_timestamps_are_rejected_without_truncation` ran **2 tests with 5 failures**: all four wrong denominator states were accepted, as was an attempt at `.1234569Z` completed earlier at `.1234561Z`. Correct denial now requires justified N/A. Both schema and runtime reject more than six fractional digits; a six-digit forward-time case succeeds. The final focused command passes **24 tests**, and focused Ruff lint/format and mypy checks pass again. Independent read-only re-review remains separate from these implementation checks.
