## Findings

1. **Blocker — launcher environment inheritance.** `spikes/full_graph/spike/launcher.py` calls `subprocess.run` for OpenShell CLI without an explicit environment. A key exported in the parent shell would be inherited by the CLI child. Pass a minimal nonsecret environment, with a synthetic canary test proving `RESEARCH_OPENAI_API_KEY` is absent from every child. This review did **not** establish that a key entered a sandbox; no real key was supplied.
2. **Blocker — nested relay payload.** `spikes/full_graph/spike/relay.py` validates selected outer fields and forwards the original body. Local probes accepted an image content part and an arbitrary nested field; `tool_calls: null` raised an uncaught exception. Validate a recursive text-only, role-specific schema, reject unknown fields with bounded errors, and construct the upstream request only from approved values. The selected model [supports image input](https://developers.openai.com/api/docs/models/gpt-5.6-sol), so the modality gap matters.
3. **Important — copied stage ID is not sender proof.** The spike's stage string is copyable. Its wrong-stage check establishes manifest consistency, not denial of a copied same-stage bearer. Clarify [CR-0012](../change-requests/CR-0012-full-graph-runtime-spike.md) and [its ToDo](../todos/CR-0012-full-graph-runtime-spike.md). Track Phase 0 per-attempt Job API and model-gate binding separately from Phase 1 sender-constrained raw-bearer denial, preserving the documented public-prototype limit.
4. **Important — active cancellation untested.** Normal completion and sandbox deletion were observed, but the synchronous launcher did not prove teardown during an active graph. Use a delayed synthetic model stub, cancel/delete during execution, and observe worker termination, no later model or fixture requests, and sandbox absence.
5. **Important — route policy fields absent.** The route object and example did not enforce their documented data class or credential mode. Implement exact class/mode admission and tests before real traffic, or revise the design so classification is explicitly an operator control without a code-enforcement claim.
