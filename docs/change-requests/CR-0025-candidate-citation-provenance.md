## Impact and decision

The current packet builder verifies that custodian-supplied citation IDs and quotes match approved source snapshots, and CR-0024 requires the reviewed answer text to equal the raw answer text. Neither proves that the **candidate emitted the packet's citations**. Current control-review completed rows bind a raw-answer hash and artifact reference but no per-citation extraction or decision. A custodian could add a true source quote to a wrong or uncited candidate answer and obtain internally consistent signed packet, control, witness, and scorecard artifacts. This is a candidate-output-to-evaluator evidence boundary distinct from whether a human judges the cited material supportive.

Before observed use, an independent control reviewer compares the complete ordered packet citation list with an original retained candidate-run artifact and a versioned per-cell citation-extraction record. The record accounts for **every** native reference by locator, method, source context, and one outcome: faithfully `mapped` to an approved visible source span or document view; `unmappable_unsupported` within allowed context; or `out_of_view_control_violation`. Only mapped spans enter the packet citation array. `Corroborated` means complete faithful accounting, not universal citation support; an omitted, altered, invented, or forbidden-source reference blocks. Normalized offsets are zero-based/end-exclusive Python string indices into exact decoded approved source text without Unicode normalization, so product-specific profiles must convert native byte or UTF-16 offsets and exact-match. A document-level native link cannot be promoted to a favorable pinpoint quote. An otherwise completed run with an accounted but uncheckable allowed reference stays completed and receives no citation support; a preregistered evaluator/access/capture failure with independent evidence is the only deferral route. **After the complete manifest and packets have been independently matched to the approved candidate×case raw-observation, concealed-assignment, and noncompleted-disposition matrix, but before any packet or target is delivered**, the control reviewer signs a per-cell `corroborated` or blocked preliminary decision over exact packet/manifest identities, canonical corpus/source/rubric digests, original artifact/extraction digests, and the packet citation **count plus canonical array digest**. The full citation list remains in the signed packet and extraction record. The distributor validates the preliminary signature, independently pinned inputs and key, full matrix, held-FD packet/manifest bytes, and independent delivery order; it retains every signed decision and permits only one active decision per cell. A blocked decision can be corrected only by a documented superseding new frozen attempt before any delivery, never by silently replacing it. **After blind reviews**, final control review v3 embeds the same exact preliminary JSON bytes/signature and signs complete labeled candidate-run digests; witness v4 freezes them before label reveal. A later witness cannot repair early or selective packet release.

The coordinated proposed v3 migration embeds the **exact signed preliminary attestation bytes and detached signature** in each restricted final control-review v3 completed-cell row. The scorer verifies those embedded bytes/signatures against the separately pinned control key and matches the attested packet/manifest IDs, raw hashes, and canonical input digests to the exact reviewed bytes; witness receipt v4 freezes the final control file before label reveal. Separately retained trusted timestamp or append-only distribution evidence is required to prove the earlier delivery order. This keeps the scorer-binding path catalog v2 shape unchanged and adds bounded v3 control-review size limits rather than an untrusted new artifact path. Missing, changed, oversized, or later-equivalent preliminary bytes deny. Scorecard v5 may use the proven citation list only after this chain passes alongside CR-0021/0022. The current v2 path remains **ineligible for observed citation scoring** until proof is implemented and independently reviewed; no v2 artifact is migrated in place. The original product run and extraction evidence stay in restricted approved custody, not the blind packet. A signature attests the control reviewer's check, while product-event truth, trusted submission time, and honest human judgment remain external gates.

At packet delivery, the distributor passes the **same immutable FD-read, preliminarily verified packet bytes** to both target derivation and the reviewer, with no pathname reopen or reserialization. The reviewer edge hashes its exact received bytes, checks packet ID and raw SHA-256 against the preliminary attestation before display, and records the digest in delivery evidence. Packet A's pre-distribution signature cannot authorize a swapped packet B or a label-bearing delivered view.

**Exact v1 contract for the isolated verifier slice.** The [v3 primary design](../design/matched-evaluation-contract-v3.md#candidate-citation-provenance-precondition) fixes a strict `pre_distribution_citation_attestation` object with candidate/case/run/control-reviewer IDs, packet ID/raw hash, complete manifest raw hash and canonical corpus/source/rubric digests, original artifact/extraction-record raw hashes, `citation_count`, `citation_spans_sha256`, decision, and bounded submission-time reference. The full ordered citation array remains in the signed packet and retained extraction record; its digest is computed from `json.dumps(..., ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False).encode("utf-8")` with no Unicode normalization. Only `blocked` carries a reason; only `corroborated` may pass. The detached signature covers `b"openshell-deep-research/pre-distribution-citation-attestation/v1\n" + exact_attestation_json_bytes` using the pinned `openssl dgst -sha256 -verify` profile and independently supplied public-key raw digest. Deny duplicate/extra fields and JSON integral-float spellings in integer fields at runtime, even if JSON Schema accepts them; wrong raw or canonical pins; any manifest packet ID duplicate, packet-count/list mismatch, or target entry not uniquely binding the exact packet hash; wrong attestation/packet/independently expected case ID or mismatched question/ordered visible source view; out-of-view, non-source-exact, or duplicate packet spans; more than 32 citations; attestation over 32 KiB; or signature over 8 KiB. The isolated helper is **binding-only**. Before distributor implementation, specify the versioned native extraction record, control-key register, complete-matrix/decision ledger, and append-only delivery record contracts named in the paired ToDo. The helper cannot establish product extraction truth, signer role/strength/revocation, matrix completeness, trusted time, held-FD custody, or reviewer-edge identity. Numeric per-product original-artifact and extraction-record loader bounds and oversize-denial proof are required before distributor integration.

## Accepted and denied behavior

- **Accept:** A candidate-native citation maps faithfully to an approved visible source span or complete linked document, with every native reference accounted for and the exact packet/extraction/manifest identities signed before packet/target delivery. An explicitly unmappable reference in allowed context stays in a completed run but earns no citation support. The blind reviewer judges support only from the mapped spans actually emitted by the candidate.
- **Deny:** A source-exact quote invented, altered, dropped, or attributed to the wrong run by the custodian; an out-of-view or forbidden native reference laundered as unsupported; a custodian-added packet citation despite no native citation in an otherwise equal raw answer; a source link mapped to another source or to an invented pinpoint quote; wrong case/question/ordered visible source view; an incomplete manifest matrix or replaced blocked decision; changed/swapped packet or manifest after preliminary signature; missing/changed extraction digest or self-asserted control/key/time decision; preliminary attestation accepted after packet **or target** delivery; or a fully re-signed internal bundle without independently retained native and delivery evidence. Source-exact packet text alone never proves candidate provenance.

## Risk, dependencies, and disable path

The risk is a false citation-quality advantage in the matched platform decision. Product-specific extraction must account for unsupported and forbidden native references without exposing candidate identity to blind reviewers. An accounted uncheckable allowed reference earns no support credit; a forbidden-source reference blocks as a control violation. Only the preregistered evaluator/access/capture failure rule permits an independently evidenced deferral, applied equally to all arms. This CR depends on CR-0011/0024 packet custody and coordinates its control-review version with CR-0021/0022. Withhold packet distribution, signed citation readiness, and SEL use until native extraction, control-key qualification, full-matrix and delivery ledger, red/green proofs, observed product-specific evidence, and independent review pass. No production source connector is enabled by this work.
