## Change request

Create 20–30 versioned, approved public/synthetic research cases and a human-review rubric before candidate runs. Use the same cases, source permissions, evidence shape, and cost/latency accounting for the available ChatGPT Enterprise path, a restricted worker, and a full-graph OpenShell worker. Record tenant entitlements and actual candidate versions. Check whether an approved read-only ChatGPT `search`/`fetch` MCP or plugin path removes the gap. Treat unavailable connectors, Replit, and unapproved private data as deferred, never as candidate failures. Collect raw run IDs and a written decision mapping each unmet control to the narrowest custom scope. Before quality review, deliver randomized anonymized answer/source packets, retain a separate concealed candidate/run mapping, freeze signed or timestamped blind reviews, and unblind only after the reviewer artifacts are committed. The labeled candidate-run schema is a restricted custodian assembly and later scorecard input format, never a packet shown to blind quality reviewers.

For the signed-binding slice, the concealed-map custodian assembles candidate-run v2 objects from the completed blind quality reviews and explicit deferred/failed dispositions in restricted custody **before** public label release. A separate control reviewer may see labeled runs and independently retained raw/source/tenant events, but blind quality reviewers see only anonymous **completed-cell** packets. The control reviewer signs exact canonical complete v2 run digests and every cell's control evidence, including a bounded reason and independently reviewed evidence reference for a noncompleted cell; no answer or quality score is invented for it. Versioned raw observations, packet manifest, concealed map, and scorer binding v2 enumerate the full candidate×case disposition matrix. A witness receipt v3 binds the control-review v2 bytes and detached signature, packet/map/review/raw hashes, trusted signer IDs/key digests, and that full matrix before unblind. The scorer re-verifies the signed bytes and separately supplied trust pins, maps exactly one quality review to each completed packet, compares all v2 run fields, and emits scorecard v4 with an explicit binding status. A required deferred/failed cell keeps readiness `incomplete` unless a verified completed-cell observed violation blocks; it never counts as a passing source-permission test. Publish a scorecard only to a fresh exclusive no-follow output path whose resolved physical path has a scorer-UID-owned exact mode-0700 ancestor, whose route contains no symlink components, whose ancestor entries cannot be renamed by another UID, and which cannot alias any consumed input. Require a run-specific success check. Any supplied candidate or binding-catalog run must require that private file path and must not print the labeled report to stdout or stderr; any invalid candidate/binding input emits only a bounded generic error with no attacker-controlled field, path, or source text. Only a zero-run, no-binding `--allow-incomplete` invocation may emit a fixed three-field status summary on stdout; a full scorecard always needs the private output file. Independent witness/key/time custody and the truth of source/tenant events remain external review gates.

This v2 binding also does not yet prove that custodian-supplied packet citations came from the original candidate output. [CR-0025](CR-0025-candidate-citation-provenance.md) / [ToDo](../todos/CR-0025-candidate-citation-provenance.md) requires an independent pre-distribution native-citation extraction attestation carried into the later control/witness record. The v2 path remains ineligible for observed citation scoring until that separate control passes; a source-exact quote in the packet alone is insufficient.

## Required behavior

- **Accept:** The frozen corpus and rubric precede runs; each registered completed case's behavior, cited source families, actual allowed/denied probes, and ordered same-subject/resource revocation transition match its preregistered fixture. Freeze the complete predeclared candidate×case **disposition matrix** before any label reveal; only completed cells receive answer packets and blind quality scores. Per-case factual support, citation spans, completeness, abstention, permission behavior, user effort, latency, and cost are scored with reviewer provenance. For candidate-run v2's single completed review object, require exactly one signed blind quality review per packet and separately corroborated, signed control flags/events. A witness receipt v3 freezes the signed control review v2 and all packet/map/review/raw hashes before label release. The scorer verifies the complete v2 run digest, exact completed-cell score/source/control mapping, and signed noncompleted-cell status/reason/evidence before scorecard v4 may report local binding. Publish a scorecard only to a fresh exclusive no-follow output path that cannot alias any consumed input, and require a run-specific success check. A human-reviewed scorecard then states real entitlement, version, unavailable paths, four-control coverage, and the SEL-01/02/05 decision. The full build proceeds only after SEL-04 proof is joined to this decision.
- **Deny:** A category label or uncited allowed source cannot stand in for an actual cross-source or prompt-injection case; a denial alone cannot stand in for revocation. Missing candidate access, skipped or fabricated cells, partial early label reveal, an old receipt, multiple reviews for one completed packet, unbound or changed v2 metadata/scores/probes/control flags/dispositions after freeze, wrong signer/key pin, different source permissions, schema-invalid/v1 candidate records, unsupported citation IDs, an untested connector, a stale/reused scorecard output path, input/output alias, or an output path inside the **verified** reviewer packet directory despite a changed catalog or intermediate output symlink, a lexical private ancestor resolving to a public writable physical output parent, a missing output path that sends candidate labels/scores into stdout or ordinary logs, a symlinked output route or writable nonsticky ancestor that lets another UID replace the lexical report after success, or a malformed field echoed to stderr cannot silently produce positive readiness. The opened output parent must be the validated safe directory held through verification and publication. Mutable score/verify mismatch and nonfinite aggregate metrics also deny. Candidate-supplied probe, control-flag, disposition and acknowledgement references are assertions until independently matched to source/tenant events. Synthetic cases are never described as proof of private-source authorization.

**Output and packet identity subgate.** A successful scorer invocation needs a fresh output path with at least one scorer-UID-owned exact mode-0700 ancestor on the resolved physical output route, checked at open and each output recheck. Reject every symlink component in the lexical output route. Before signed verification, walk the canonical parent with no-follow directory FDs and require every ancestor entry to resist replacement by another UID: each component belongs to root or the scorer UID; a parent writable by group/other is accepted only when its sticky bit and root/scorer ownership of parent and child protect that entry (for example, root-owned sticky `/private/tmp` with a scorer-owned private child). Hold the output-parent FD through exclusive mode-0600 publication and recheck the route before success. A private 0700 child under a writable nonsticky parent is not a stable consumer path. The signed verifier must list and read packets from the **same pinned packet-directory FD** used to exclude output from the verified packet tree; a pathname A→B→A switch during verification must fail even when B contains a valid signed copy and A is restored afterward. [Independent evidence](../evidence/CR-0011-output-parent-fd-independent-review-2026-10-26.md) shows why output-parent hardening alone did not meet this existing deny rule. The verifier/physical-route, stdout/stderr log-custody, and post-exit route-stability corrections passed [separate final read-only code review](../evidence/CR-0011-0024-final-custody-independent-review-2026-10-26.md). Keep the scorer disabled for observed use until approved inputs, external witness/original-run truth, and remaining CR-0021/0022/0025 gates pass.

**Pre-reveal identity-custody subgate.** The concealed map and later unblinded assembly are labeled artifacts. A path check followed by `_write_exclusive` on a mutable absolute pathname can redirect either artifact into the reviewer packet directory through an intermediate symlink. Preparation must publish its packet files/manifest through the created packet-directory FD and its map through a separately held owner-only private-parent FD; unblinding must publish through a safe held private output-parent FD. Check actual inode ancestry and separation, use exclusive mode-0600 creation, and deny a path switch before or during writes. On failure, cleanup may remove only positively identified artifacts created by that invocation; an uncertain pathname must be left for manual reconciliation rather than recursively deleting an unrelated directory. Red-first map/unblind leak, route/inode substitution, and cleanup-canary regressions now pass locally. The final reviewer found that an older packet symlink-switch test now denies before its held-FD injection hook runs; a no-symlink post-open packet-directory rename and cleanup regression now permanently exercises that proof; its hook fired and the test passed, with full local gates green. The [separate final read-only code review](../evidence/CR-0011-0024-final-custody-independent-review-2026-10-26.md) found no remaining scoped Blocker/Important in this local custody correction. No packet distribution or label release is allowed until external witness custody and other open selection gates pass.

**Caller file-lifetime correction.** The [writer-local review](../evidence/CR-0011-linux-publication-fd-review-2026-10-26.md) identified an adjacent lifetime gap: returning a device/inode pair after closing the file does not pin that identity for the caller's later checks or rollback. Retain each created concealed-map, unblinded-output, packet, and manifest file handle until its owning operation finishes final validation and any rollback, then close it on success and failure. A replacement must deny without deleting a foreign file; normal publication and cleanup of owned artifacts must still work. This implements the existing custody rule under DR-FEAS-001 without changing artifact fields or signed versions. It does not make pathname checking and unlink atomic against a hostile process sharing the custodian UID; separate OS custody remains required. The [red-first tests](../evidence/CR-0011-caller-file-lifetime-tdd-2026-10-26.md) and [independent review](../evidence/CR-0011-caller-file-lifetime-independent-review-2026-10-26.md) record the bounded local correction; observed selection remains closed.

## Risk and disable path

The risks are selection bias, misleading claims about incumbent gaps, and sensitive test data in ordinary artifacts. Use approved synthetic/public cases and immutable case/rubric versions; quarantine any unapproved case or trace. A new finding invalidating comparability pauses the decision, updates the versioned corpus through review, and reruns all affected candidates. No production feature is enabled by this CR alone.

## Dependency and closure gate

The draft corpus, v2 scorer, and local blind-packet utility were developed without candidate access. Actual matched results require approved corpus/rubric digests, independently witnessed blind reviews and their binding to scorer input, an approved real model/runtime, an authorized ChatGPT Enterprise tester, and source/tenant corroboration of probe evidence. Keep this CR `In progress` until the frozen cases, observed scored runs, SEL-01/02/05 record, independent review, and SEL-04 runtime evidence are linked in the paired ToDo. Documentation or simulated scores alone do not close it.
